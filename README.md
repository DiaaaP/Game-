# Dock Shift

Игра о грузовых рейсах в северном порту. Одиночная смена включает пять доставок, а смена вдвоём по сети — десять. У каждого участка своя механика. В конце смены игра показывает результаты всех доставок.

| Участок | Основной груз | Дополнительный груз для двоих | Задача |
| --- | --- | --- | --- |
| Паромный терминал | Почтовая посылка | Сигнальный буй | Опустить разводной мост нажимными площадками, пройти досмотр и найти диспетчера. Вдвоём нужно одновременно занять обе площадки. |
| Сортировочный цех | Лебёдочный редуктор | Кассета роликов | Положить груз на ленту. После сканирования откроются ворота для курьеров. Забрать груз с другой стороны и довезти до отгрузки. |
| Портовый архив | Фарфоровый экспонат | Карта старой гавани | Сверяться с отсчётом и переносить груз через три сканера, пока лучи погашены. |
| Холодильный склад | Термоконтейнер | Контрольная проба | На каждой из четырёх станций дождаться охлаждения до 23%. Вне синей зоны после подбора груз нагревается. |
| Приливная подстанция | Модуль питания | Резервный аккумулятор | Пройти по мостику через насосный узел, совместить груз с разъёмом клавишей Q и отпустить его над приёмкой. |

## Как играть

- **Один игрок.** Нажмите **Одиночная игра** в главном меню.
- **Два игрока.** Один выбирает **Создать комнату**, второй — **Войти по IP** и указывает адрес первого компьютера. Оба отмечают готовность, затем хозяин комнаты запускает смену. На каждом участке оба груза доступны сразу. Каждый курьер может нести по одному, а следующий участок откроется после приёмки обоих.
- В меню **Настройки** можно изменить общую громкость и чувствительность мыши.
- Маркер и подсказка показывают следующую остановку. Для аккуратной постановки опустите взгляд и нажмите E. Дождитесь, пока предмет перестанет двигаться и приёмка подтвердит доставку.
- При поломке, перегреве или падении груза за пределы уровня повторяется текущий рейс. Уже принятые грузы и очки сохраняются.

| Клавиша | Действие |
| --- | --- |
| W A S D | Перемещение |
| Мышь | Обзор |
| Space | Прыжок |
| Ctrl / C | Присесть |
| E | Поднять или отпустить груз |
| Q | Повернуть груз; на подстанции совместить его с разъёмом |
| R | Повторить доставку своего груза |
| Esc | Пауза |
| F1 | Сетевая диагностика |

## Запуск исходников и сборка

1. Распакуйте архив с исходниками.
2. В Unity Hub выберите **Add project from disk** и укажите папку `game`, в которой лежат `Assets`, `Packages` и `ProjectSettings`.
3. Откройте проект в **Unity 6000.3.26f1** и дождитесь первого импорта.
4. Откройте сцену `Assets/DeliveryImpossible/Scenes/MovementTest.unity` и нажмите **Play**.
5. Для сборки используйте **File → Build Profiles → Windows**. Запустите готовый `Dock Shift.exe` из папки сборки.

Для проверки вдвоём на одном компьютере запустите две копии игры и подключите вторую по адресу `127.0.0.1`. Аргумент `--auto-client` выполняет такое подключение автоматически. При игре по локальной сети укажите IP компьютера хозяина комнаты.

| Файл или папка | Назначение |

| `game/Assets/DeliveryImpossible/Scripts/NetworkDeliveryOrder.cs` | Рейсы, контрольные точки, повторы и результаты |
| `game/Assets/DeliveryImpossible/Scripts/DeliveryCourse.cs` | Мост, лента, сканеры, охлаждение и разъёмы |
| `game/Assets/DeliveryImpossible/Scripts/NetworkGrabber.cs` | Взаимодействие с грузом и его отпускание по физике |
| `game/Assets/DeliveryImpossible/Scripts/NetworkLobbyUi.cs` | Главное меню, комната, пауза и итоги |
| `game/Assets/DeliveryImpossible/Scripts/NetworkOrderHud.cs` | Цель, направление, температура и отсчёты |
| `game/Assets/DeliveryImpossible/Editor/NorthQuayRoutes.cs` | Геометрия маршрутов и расстановка объектов |
| `game/Assets/DeliveryImpossible/Scenes/MovementTest.unity` | Сохранённая сцена со всеми пятью участками |

Проект использует C#, URP, Unity Input System, TextMesh Pro и [Mirror](https://github.com/MirrorNetworking/Mirror).

Лицензии и ссылки на внешние материалы лежат в `Assets/DeliveryImpossible/PortSurfaces/Credits.txt` и `Assets/DeliveryImpossible/Models/Credits.txt`. Проект основан на [исходной игре DiaaaP](https://github.com/DiaaaP/Game-).
